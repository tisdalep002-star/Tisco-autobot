# MYTHOS Basic Usage Examples

Simple examples to get started with MYTHOS.

## 1. List Files in Directory

```
⬡ › list all files in the current directory
```

MYTHOS will execute `ls` or `dir` command and show results.

## 2. Create a File

```
⬡ › create a file called hello.py that prints hello world
```

MYTHOS will write the Python script to disk.

## 3. Check Python Version

```
⬡ › what version of python am i running
```

MYTHOS will run `python --version` and report back.

## 4. Count Lines in a File

```
⬡ › how many lines are in mythos.py
```

MYTHOS will use `wc -l` to count lines.

## 5. Check Token Count

```
⬡ › /tokens The quick brown fox jumps over the lazy dog
```

Inspect tokenization of the provided text.

## 6. Search for Text in Files

```
⬡ › find all occurrences of import statements in python files
```

MYTHOS will use `grep` to search files.

## 7. Get System Information

```
⬡ › show me my system information
```

MYTHOS will run system commands to gather info.

## 8. Create a Directory Structure

```
⬡ › create a directory structure for a python project
```

MYTHOS will create the necessary folders and files.

## 9. Read File Contents

```
⬡ › read the README file
```

MYTHOS will display the file contents.

## 10. Execute a Shell Command

```
⬡ › run git status
```

MYTHOS will execute the git command and show output.
